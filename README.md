# ArchNet · Facade Pattern

Learning package: a sample showing the Facade pattern, one simple entry point to several systems.

- Unity **6000.0** or newer · No dependency.
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/DesignPatternFacade.git
```

## Use

*Package Manager > ArchNet - Facade Pattern > Samples > Import "Shop Facade"*, then add `ShopFacadeExample` to a GameObject and press Play.
